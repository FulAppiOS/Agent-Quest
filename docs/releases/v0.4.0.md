### New in 0.4.0

- **Xcode agent discovery** — on macOS, Agent Quest automatically finds compatible local Claude Agent and Codex session logs from Xcode, alongside the existing terminal and app locations. Folders created after startup are picked up without restarting Agent Quest.
- **Activities that match the work** — reading and searching send heroes to the Library, editing to the Forge, builds and tests to the Arena, and issue diagnostics to the Alchemist. Xcode prompts and tool calls are recognized in the supported Claude and Codex log formats.
- **Xcode badges and project names** — distinguish IDE sessions in the village, Party Bar, details, activity feed and context list. Main-session names come from the project path; profiles distinguish Xcode · Claude and Xcode · Codex. Using Xcode tools from an external terminal keeps the terminal session’s source identity.
- **More reliable live updates** — partial log writes are held until complete, Codex invocation/completion pairs are deduplicated, and Claude inside Xcode no longer depends on terminal process registrations. Codex skill inventory is collected across its detected locations.
- **A clearer startup** — an immediate loading screen follows asset loading, connection and village preparation. The map and panels appear after the first complete village frame, with a useful message if initialization fails.

### Start with Xcode

1. Run Agent Quest on the same Mac and under the same user account as Xcode.
2. Choose Claude Agent or Codex inside Xcode and send a prompt.
3. Watch the session appear with its Xcode badge, normally within the 2–3 second polling interval.

Xcode may create its session folders only after the first prompt. Agent Quest watches:

```text
~/Library/Developer/Xcode/CodingAssistant/ClaudeAgentConfig/projects
~/Library/Developer/Xcode/CodingAssistant/codex/sessions
```

Logs must be locally available and readable. Files older than three hours are skipped on startup and picked up when they resume. No optional terminal Claude hook is needed for Xcode sessions. This is monitoring of compatible local Claude/Codex logs, not control of Xcode or support for every chat provider. Agent login status is not inferred from an empty folder.

### Updating from 0.3.1 or earlier

Stop Agent Quest with Ctrl+C in its terminal, then run:

```bash
agentquest update
agentquest
```

For a manual installation, run these commands from your Agent Quest folder after stopping the app:

```bash
git pull --ff-only && bun install
bun start
```

Refresh the dashboard after restarting. These commands follow `main`, which may contain changes newer than the announced release. Preserve and resolve any local changes if Git reports a conflict. Version 0.3.1 can notify you when this stable release is published; earlier versions require a manual update.

Context monitoring, skill and plugin telemetry, subagent families, reports and the map editor remain included. See the [0.3.1 release notes](https://github.com/FulAppiOS/Agent-Quest/releases/tag/v0.3.1) for release notifications and the earlier feature overview.
